# Вход в TPAM через Telegram

Вход как в само приложение Telegram: **номер телефона → код из Telegram → облачный пароль** (если включён). Никому не передавайте код, облачный пароль и ссылки с ними, в том числе ИИ-ассистентам.

## Для администратора: один раз при установке

1. Откройте https://my.telegram.org, войдите по номеру, выберите **API development tools**.
2. Заполните форму: App title `TPAM`, Short name латиницей (например `tpamlocal`), Platform `Desktop`. Нажмите **Create application**.
3. Укажите **App api_id** и **App api_hash**:
   - **локально** — сайт сам попросит их при первом открытии на этом компьютере (сохраняются в «Диспетчере учётных данных Windows»);
   - **на сервере** — в `.env` (`TPAM_API_ID`, `TPAM_API_HASH`), см. [DEPLOY.md](DEPLOY.md).
4. Войдите первым — вы станете администратором.

> Если форма my.telegram.org отвечает «ERROR», попробуйте другой браузер или отключите VPN и блокировщик рекламы.

## Для всех: вход

1. Откройте сайт TPAM → введите номер в международном формате → отметьте согласие с условиями → **Получить код**.
2. Введите код из сообщения от официального аккаунта **Telegram**. Не пересылайте его никуда, даже в «Избранное»: Telegram отменит такой вход.
3. Если включена двухэтапная аутентификация, введите облачный пароль. Он передаётся в Telegram и не сохраняется.

Сеанс в браузере действует 30 дней. Выйти на этом устройстве или на всех устройствах сразу можно в разделе «Аккаунт».

Рекомендуем включить облачный пароль в Telegram: Настройки → Конфиденциальность → Облачный пароль.

## Что проверить после подключения

- В официальном Telegram: Настройки → Устройства. Там появится сеанс **«TPAM (веб-клиент)»**. Повторный вход в TPAM заменяет его: одновременно активен только один сеанс TPAM.
- Telegram может прислать уведомление о новом входе. Это нормально: вход выполнили вы.
- В первые 24 часа новая сессия не может завершать другие сеансы. Это ограничение Telegram.

## Первые шаги с автоматизацией (рекомендуется)

1. Создайте правило: оно появится в **тестовом режиме (dry-run)**.
2. Включите главный выключатель автоматизации.
3. Несколько дней смотрите в **Журнале**, на какие сообщения правило ответило бы.
4. Только после этого выключите dry-run у правила.

## Отключение и экстренные действия

- **Отключение:** Аккаунт → «Отключить Telegram». Сессия завершается в Telegram; по желанию удаляются и все ваши данные с сервера.
- **Если файл сессии мог попасть к посторонним:** в официальном Telegram откройте Настройки → Устройства и завершите сеанс «TPAM». Затем удалите `%LOCALAPPDATA%\tpam\telegram.session`.
- **Чужой браузер:** Аккаунт → «Выйти на всех устройствах».
- **Если Telegram ограничил отправку («подозрение на спам»):** TPAM сам выключит автоматизацию. Сделайте паузу и не повторяйте массовые действия.

## Частые ошибки

| Сообщение | Что делать |
|---|---|
| «Сервер настроен неверно (API ID)» | Администратору: проверить API ID и API HASH с my.telegram.org |
| «Слишком много запросов кода» | Защита от злоупотреблений: подождите час или попробуйте позже |
| «Регистрация закрыта» | Администратор закрыл регистрацию новых пользователей |
| «Неверный код» | Проверьте последнее сообщение от Telegram, введите код без пробелов |
| «Срок действия кода истёк» | Нажмите «Изменить номер» и запросите новый код |
| «Telegram просит подождать N с» | Это защита Telegram от частых попыток (FloodWait). Подождите указанное время |
| «Нет соединения с Telegram» | Проверьте интернет и нажмите «Переподключить» в разделе «Аккаунт» |
| «Сессия Telegram завершена» | Сеанс TPAM завершили в «Устройствах». Выйдите и войдите снова по номеру |

## Автоответы с ИИ

1. Автоматизация → карточка **«ИИ-ассистент»** → вставьте ключ с https://console.anthropic.com/settings/keys (баланс нужно пополнить). Ключ проверяется и сохраняется в «Диспетчере учётных данных Windows».
2. Заполните «Кто отвечает и как» и «База знаний» — ассистент опирается только на этот текст и историю чата, факты не выдумывает.
3. В «Проверить ассистента» напишите пример сообщения и посмотрите ответ (ничего не отправляется).
4. Создайте правило: «Как отвечать» → **«Ответ составит ИИ»**. Оставьте тестовый режим, включите автоматизацию и несколько дней смотрите в Журнале, что ответил бы ИИ.
5. Когда ответы устраивают — выключите тестовый режим у правила.

ИИ вызывается только после проверки всех ограничителей (боты, паузы, лимиты), поэтому пропущенные сообщения ничего не стоят. Каждый ответ — платный запрос к Anthropic; текст переписки уходит в Anthropic для составления ответа.

## Архив: сохранение удалённых и изменённых сообщений

- Новым пользователям **выключен по умолчанию**: каждый включает его сам в «Архив → Настройки». У администратора, перенесённого из прошлой версии, настройки сохранены.
- Копия создаётся в момент получения сообщения, поэтому **сервер TPAM должен работать**. Локально включите «Запускать TPAM вместе с Windows» (только администратор); на VPS сервер работает постоянно.
- Удалённое сообщение остаётся в чате с пометкой «Удалено · сохранено в архиве» и попадает в фильтр «Удалённые». Telegram не сообщает, кто удалил: собеседник или вы с другого устройства.
- Исчезающие фото и видео («просмотр один раз») не сохраняются. Секретные чаты недоступны.
- Старую переписку можно загрузить через «Архив → Импорт»: Telegram Desktop → Настройки → Продвинутые → Экспорт данных → формат «Машиночитаемый JSON». Папку экспорта после импорта не удаляйте: фото и файлы берутся из неё.
- Архив хранится только на этом компьютере, в `%LOCALAPPDATA%\tpam`. Не публикуйте и не пересылайте удалённое без согласия автора.
